# Lục Trà Thăng Hoa — trang ghim

Trang nhỏ để **ghim ứng dụng ra màn hình chính điện thoại với biểu tượng logo quán** (ghim thẳng link Apps Script sẽ ra chữ "L").
Mở trang → tự chuyển sang ứng dụng (Web App Apps Script).

- Link trang: https://tc-1209.github.io/luctra-ghim/
- **Ghim:** mở `https://tc-1209.github.io/luctra-ghim/#ghim` bằng Safari (iPhone) / Chrome (Android) → làm theo hướng dẫn trên trang.
- Ghim thẳng từng hệ thống: `?app=ketca#ghim`, `?app=ship#ghim`, `?app=nhansu#ghim`.
- Đổi link ứng dụng: sửa dòng `var APP_URL = '…/exec';` trong `index.html`.

Mã nguồn và hướng dẫn đầy đủ: repo `AppScript_ThangHoa`, thư mục `trang-ghim/`.
